## Rules
- Config Triage_Enabled blank/FALSE = OFF. Nothing is read, written or shown.
- Only new work orders from tenant, owner, email, manual types (and the Buildium email intake) are triaged. Scope, add-on, recurring, turnover, delivery, split, duplicate are never triaged.
- Never lowers a Priority. Emergency raises it to urgent (audit-logged).
- Fail open and loud: a triage failure never fails the work order; failed Ops_Telemetry row + P2 failure-ledger row; Hub shows NOT TRIAGED.
- Config keys: Triage_Enabled, Triage_Keywords (JSON, replaces a tier's built-in words), Triage_SLA_Hours (JSON).
